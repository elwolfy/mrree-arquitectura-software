# Asignación A4 — Caché Distribuida Cache-Aside con Redis y Actualización del Modelo C4

- **Módulos:** `docs/c4/` (Modelo C4 en Structurizr DSL), `docs/adr/` y `m3-datos/tramites-service`
- **Conceptos del curso:** Caché distribuida (*Cache-Aside* / *Lazy Loading*), invalidación impulsada por eventos en proyecciones CQRS (sección **3.4** del plan) y arquitectura como código con el **Modelo C4** en Structurizr DSL (sección **4.1** del plan).
- **Tiempo estimado total:** $\approx 45\text{ minutos}$ (Tarea 1 conceptual $\approx 20\text{ min}$ + Tarea 2 práctica $\approx 25\text{ min}$).

---

## 1. Objetivo y Contexto

Cuando un ciudadano consulta el seguimiento de su trámite en la plataforma consular (`GET /api/tramites/{id}`), el frontend realiza un sondeo cada 2 segundos para detectar cuándo la Saga avanza de `PENDIENTE_PAGO` a `EN_EMISION` y finalmente a `EMITIDO`.

En la rama `main`:
1. La vista de contenedores del modelo C4 ([docs/c4/workspace.dsl](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/docs/c4/workspace.dsl)) incluye a PostgreSQL y RabbitMQ, pero **no incluye el contenedor Redis** (tiene un comentario didáctico indicando el punto exacto donde debe agregarse).
2. En `m3-datos/tramites-service`, el puerto de salida [CacheConsultaTramitePort.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/application/port/out/CacheConsultaTramitePort.java) ya es invocado por [ConsultarTramiteService.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/application/service/ConsultarTramiteService.java) (que marca `X-Cache: HIT` o `X-Cache: MISS` en [TramiteController.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/adapter/in/web/TramiteController.java)) y por [ProyectorVistaTramite.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/application/proyeccion/ProyectorVistaTramite.java) (que llama a `cacheConsultaTramitePort.invalidar(tramite.getId())` cada vez que cambia el estado). Sin embargo, en `main` solo está activo el adaptador nulo [CacheNulaConsultaTramiteAdapter.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/adapter/out/cache/CacheNulaConsultaTramiteAdapter.java) (`cache.consulta-tramite.tipo=nula`), por lo que todas las consultas responden `X-Cache: MISS`.

## 3. Tarea 2 — Práctica ($\approx 25\text{ min}$)

### 3.1 Archivos Involucrados y Modelo de Referencia

- **Clase a crear:** `m3-datos/tramites-service/src/main/java/pe/utec/consular/tramites/adapter/out/cache/RedisCacheConsultaTramiteAdapter.java`.
- **Prueba de aceptación a habilitar:** [RedisCacheConsultaTramiteAdapterTest.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/test/java/pe/utec/consular/tramites/cache/RedisCacheConsultaTramiteAdapterTest.java) (retirar `@Disabled("Asignación A4")`).

### 3.2 Pasos de Implementación

1. Cree `RedisCacheConsultaTramiteAdapter` en el paquete `pe.utec.consular.tramites.adapter.out.cache` implementando `CacheConsultaTramitePort`:
   - Anótelo con `@Component` y `@ConditionalOnProperty(name = "cache.consulta-tramite.tipo", havingValue = "redis")`.
   - Inyecte por constructor `StringRedisTemplate`, `ObjectMapper` y `@Value("${cache.consulta-tramite.ttl-segundos:60}") long ttlSegundos`.
   - Use el formato de clave `"tramite:" + tramiteId` (`PREFIJO_CLAVE = "tramite:"`).
   - En `obtener(UUID tramiteId)`: lea el JSON desde Redis (`redisTemplate.opsForValue().get(clave)`) y deserialícelo a `VistaTramite` con `objectMapper.readValue(json, VistaTramite.class)`.
   - En `guardar(UUID id, VistaTramite vista)`: serialice la `VistaTramite` a JSON y guárdela con TTL (`redisTemplate.opsForValue().set(clave, json, Duration.ofSeconds(ttlSegundos))`).
   - En `invalidar(UUID id)`: elimine la clave en Redis (`redisTemplate.delete(clave)`).
2. Active el adaptador por defecto en `m3-datos/tramites-service/src/main/resources/application.yml` (`tipo: ${CACHE_CONSULTA_TRAMITE_TIPO:redis}`) y en `m3-datos/docker-compose.yml` (`CACHE_CONSULTA_TRAMITE_TIPO: ${CACHE_CONSULTA_TRAMITE_TIPO:-redis}`).
3. En [RedisCacheConsultaTramiteAdapterTest.java](file:///c:/Jorge-Projects/mre_arquitectura/mrree-arquitectura-software/m3-datos/tramites-service/src/test/java/pe/utec/consular/tramites/cache/RedisCacheConsultaTramiteAdapterTest.java), elimine la línea `@Disabled("Asignación A4")`.

## 5. Criterios de Aceptación Verificables

### 5.1 Prueba de Integración Automatizada en Verde

```powershell
mvn -B -f m3-datos verify -pl tramites-service -Dit.test=RedisCacheConsultaTramiteAdapterTest
```
- `RedisCacheConsultaTramiteAdapterTest` debe pasar en verde (`Failures: 0, Errors: 0, Skipped: 0`), comprobando:
  1. Primera lectura `GET /api/tramites/{id}` → `X-Cache: MISS` y escritura en Redis con clave `tramite:<id>` y TTL $\le 60\text{ s}$.
  2. Segunda lectura `GET /api/tramites/{id}` → `X-Cache: HIT`.
  3. Confirmación de pago en la Saga → invalidación automática en `ProyectorVistaTramite` → tercera lectura devuelve `X-Cache: MISS` con el nuevo estado `EN_EMISION`.

### 5.2 Verificación E2E con Docker Compose y `curl` / PowerShell

Con `m3-datos` levantado (`.\m3-datos\scripts\levantar.ps1`):

```powershell
# 1. Crear un trámite
$t = Invoke-RestMethod -Uri "http://localhost:8080/api/tramites" -Method Post -ContentType "application/json" `
  -Body '{"dni":"40000001","nombres":"Ana Perez","email":"ana@correo.lab","tipoTramite":"APOSTILLA","pais":"ES","folios":2,"idioma":"ES"}'

# 2. Primera consulta -> X-Cache: MISS
(Invoke-WebRequest -Uri "http://localhost:8080/api/tramites/$($t.id)" -UseBasicParsing).Headers["X-Cache"]

# 3. Segunda consulta inmediata -> X-Cache: HIT
(Invoke-WebRequest -Uri "http://localhost:8080/api/tramites/$($t.id)" -UseBasicParsing).Headers["X-Cache"]

# 4. Pagar el trámite (la Saga cambia el estado e invalida Redis)
Invoke-RestMethod -Uri "http://localhost:8080/api/pagos" -Method Post -ContentType "application/json" `
  -Headers @{ "Idempotency-Key" = [guid]::NewGuid().ToString() } `
  -Body "{`"tramiteId`":`"$($t.id)`",`"monto`":$($t.monto)}"
Start-Sleep -Seconds 2

# 5. Consulta tras cambio de estado -> X-Cache: MISS
(Invoke-WebRequest -Uri "http://localhost:8080/api/tramites/$($t.id)" -UseBasicParsing).Headers["X-Cache"]
```
